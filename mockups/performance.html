Performance Guide: FPS Fixes & Best Settings

UPDATED AUG 30, 2026 · VERIFIED ON PATCH 1.01 · PC / PS5 / XSX
Mission Briefing — TL;DR
  • Disable "Environment Geometry Detail" — the single biggest win, worth roughly +40 FPS on most rigs.
  • UE5 stutter is worst during airborne insertions & overwatch cams — shader compilation, improves after a few missions.
  • Recommended spec (RTX 3080 / 32GB for 1440p60) is real — this game is heavier than it looks.
  • Crashes mid-mission? Drop to Windowed Borderless + cap FPS at 60 until the next patch.

The One Setting Everyone Is Talking About

Within hours of launch, the community isolated the day-1 performance killer: Environment Geometry Detail. Multiple players report recovering around 40 frames per second from this toggle alone, with minimal visible difference in the game's small tactical arenas.

COPY Settings → Graphics → Environment Geometry Detail → OFF / LOW
# Then restart the game — the change does not fully apply live.

Known Bugs & Crash Fixes

Still crashing? Work through this checklist

Game hangs ~20s after slow-motion overwatch kills
Known camera bug. Disable "Cinematic Kill Cam" in Gameplay settings until patched.
Crash mid-mission, progress lost
Switch to Windowed Borderless, cap FPS at 60, and update GPU drivers. Bit Reactor has flagged this for Patch 1.02.
PS5 Pro frame drops
Use Performance mode, not Quality. The 120Hz output toggle currently causes instability — leave it off.
